# 测试说明

自动化测试集中在两个公开边界：前端纯 TypeScript 领域 API，以及后端 HTTP API 与临时 SQLite 数据库。

前端测试覆盖相同种子复现、合法移动、编辑保护、挑战码、BFS 最短路径、无解结果、A* 对比和输入不可变性。后端测试覆盖保存与重启恢复、幂等提交、ID 冲突、筛选、详情、删除、算法无解记录和非法路径拒绝。

界面动画、响应式布局、键盘操作和视觉辨识采用人工验收，步骤见 `ACCEPTANCE_CHECKLIST.md`。这种划分避免为 DOM 表象编写脆弱测试，同时保证算法和数据契约可重复验证。

扩大地图后，前端覆盖五档尺寸的种子复现、挑战码往返与 BFS/A* 路径长度一致性；回放测试用模拟帧时间验证 5× 进度、暂停续播和结束边界。后端覆盖 41×41、51×51 编辑快照及超过 961 个访问节点的保存、重启恢复。
