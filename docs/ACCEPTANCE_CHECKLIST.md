# 验收清单

- [ ] 11×11、21×21、31×31 均可生成；相同种子与挑战码得到相同迷宫。
- [ ] 方向键、WASD 和屏幕按钮只能让玩家进入相邻通路；到达终点后自动保存。
- [ ] BFS 与 A* 均展示访问过程、最终路径、路径长度、访问节点数与计算耗时。
- [ ] 搜索动画可暂停、以 0.5×/1×/2× 速度播放并重放。
- [ ] 编辑工具可画墙、擦除、移动起终点；不能破坏外边框、覆盖玩家或重合起终点。
- [ ] 人工构造无解迷宫后，搜索明确显示“无解”且不会伪造路径。
- [ ] 历史记录可按模式筛选、恢复完整快照、重放算法结果和删除。
- [ ] 后端暂时不可用时，手动与算法功能仍可运行，并提供保存失败重试入口。
- [ ] 刷新页面后运行历史仍存在；重复保存同一 ID 不产生重复记录。
- [ ] 在桌面和窄屏窗口中操作区域无横向溢出；键盘焦点清晰，颜色之外还有文字与形状区分。
