# 验收清单

本轮验证日期：2026-09-22。自动化项目由 Vitest、pytest、`vue-tsc` 和 Vite build 验证；浏览器项目使用本地 FastAPI 构建在 Codex 内置 Chromium 中检查。

- [x] 11×11、21×21、31×31 均可生成；相同种子与挑战码得到相同迷宫。（自动化 + 浏览器）
- [x] 方向键、WASD 和屏幕按钮只能让玩家进入相邻通路；到达终点后自动保存。（固定 11×11 迷宫手动完成 32 步并自动保存）
- [x] BFS 与 A* 均展示访问过程、最终路径、路径长度、访问节点数与计算耗时。（浏览器；31×31 A* 也已运行）
- [x] 搜索动画可暂停、以 0.5×/1×/2× 速度播放并重放。（浏览器）
- [x] 编辑工具可画墙、擦除、移动起终点；不能破坏外边框、覆盖玩家或重合起终点。（浏览器；同时验证宽画布留白下的 SVG 坐标反算）
- [x] 人工构造无解迷宫后，搜索明确显示“无解”且不会伪造路径。（固定夹具自动化）
- [x] 历史记录可按模式筛选、恢复完整快照、重放算法结果和删除。（筛选/恢复/重放使用浏览器，删除使用 HTTP + SQLite 自动化测试）
- [x] 后端暂时不可用时，手动与算法功能仍可运行，并提供保存失败重试入口。（浏览器中停止服务后完成 BFS，再启动服务并重试成功）
- [x] 刷新页面后运行历史仍存在；重复保存同一 ID 不产生重复记录。（后端重建测试 + 浏览器刷新）
- [x] 在桌面和 390px 窄屏窗口中操作区域无横向溢出；键盘焦点清晰，颜色之外还有文字与形状区分。（浏览器，`scrollWidth === clientWidth`）

## 立体观察实验分支

2026-09-22，内置 Chromium 验证：

- [x] 21×21、31×31 纸层呈现独立深度，31×31 A* 回放可在倾斜视图中观察。
- [x] 鼠标拖动和方向键调整视角，连续操作不超过 ±15°；Home 回正，Escape 返回正视。
- [x] 选择编辑工具或屏幕方向按钮会退出观察视图。
- [x] 390px 窗口中页面无横向溢出（可用宽度与滚动宽度均为 375px）；纸层深度随显示尺寸缩放。

此实验尚未在 Safari、Firefox 或真实触屏设备上验收。
