# 5 四路多路选择器的设计与仿真

## 5.1 多路选择器设计及源代码

### 5.1.1 实验目的

设计一个输入为 4 路、每路宽度为 32 位的多路选择器，掌握组合逻辑模块的 Verilog 描述方法，并通过功能仿真验证选择信号与输出信号之间的对应关系。

### 5.1.2 工作原理

四路多路选择器接收 `in0`、`in1`、`in2`、`in3` 四路 32 位数据输入，接收 2 位选择信号 `sel`，输出一个 32 位数据 `out`。选择信号的两个二进制位构成四种状态，每种状态唯一对应一路输入。当 `sel` 发生变化时，组合逻辑立即将对应输入传递到输出，不需要时钟或复位信号。

表 5.1 给出了选择信号与输出的对应关系。

| 表 5.1 四路多路选择器功能真值表 |  |  |
| --- | --- | --- |
| `sel` | 选中的输入 | `out` |
| `2'b00` | `in0` | `in0` |
| `2'b01` | `in1` | `in1` |
| `2'b10` | `in2` | `in2` |
| `2'b11` | `in3` | `in3` |

### 5.1.3 源代码

四路多路选择器源文件 `rtl/mux4_1.v` 如下。

```verilog
`timescale 1ns/1ps

// 32 位四路一选一多路选择器（4-to-1 Multiplexer）
module mux4_1 (
    input  [31:0] in0,       // 第 0 路 32 位数据输入
    input  [31:0] in1,       // 第 1 路 32 位数据输入
    input  [31:0] in2,       // 第 2 路 32 位数据输入
    input  [31:0] in3,       // 第 3 路 32 位数据输入
    input  [1:0]  sel,       // 2 位选择信号
    output reg [31:0] out    // 选中的 32 位数据输出
);

    // 组合逻辑：sel 决定哪一路输入连接到输出。
    always @(*) begin
        case (sel)
            2'b00: out = in0;
            2'b01: out = in1;
            2'b10: out = in2;
            2'b11: out = in3;
            default: out = 32'b0;
        endcase
    end

endmodule
```

程序使用 `always @(*)` 描述组合逻辑，使输入或选择信号发生变化时自动重新计算输出。`case` 语句覆盖四种有效选择状态，`default` 分支为未定义选择状态提供确定值，从而避免综合出锁存器。该模块没有时钟、复位和外部模块依赖，可以直接加入 Vivado 的 Design Sources。

## 5.2 仿真代码

### 5.2.1 仿真方案

仿真文件实例化 `mux4_1`，将四路输入固定为四个容易识别的十六进制常量，再以 20 ns 为间隔依次施加四种 `sel` 状态。采用固定测试数据可以直接从波形判断输出是否选择了正确输入，也能使四个测试区间与报告中的结果分析一一对应。

Testbench 使用 `initial` 完成一次性激励。每次选择状态保持 `#20`，在 20 ns 边界先检查已经稳定的当前组，再切换到下一组，因此四组有效区间为 0-20 ns、20-40 ns、40-60 ns 和 60-80 ns。检查语句和选择信号更新位于同一个顺序执行的 `initial` 过程，避免了并行激励造成的调度竞争。

表 5.2 给出了固定测试数据，表 5.3 给出了四组测试时序。

| 表 5.2 固定测试数据 |  |
| --- | --- |
| 信号 | 数值 |
| `in0` | `32'h11111111` |
| `in1` | `32'h22222222` |
| `in2` | `32'h33333333` |
| `in3` | `32'h44444444` |

| 表 5.3 四组测试时序 |  |  |
| --- | --- | --- |
| 组别 | 时间区间 | 预期输出 |
| 第一组 | 0-20 ns，`sel=00` | `0x11111111` |
| 第二组 | 20-40 ns，`sel=01` | `0x22222222` |
| 第三组 | 40-60 ns，`sel=10` | `0x33333333` |
| 第四组 | 60-80 ns，`sel=11` | `0x44444444` |

### 5.2.2 Testbench 源代码

仿真文件 `sim/mux4_1_tb.v` 如下。

```verilog
`timescale 1ns/1ps

module mux4_1_tb;

    reg  [31:0] in0;
    reg  [31:0] in1;
    reg  [31:0] in2;
    reg  [31:0] in3;
    reg  [1:0]  sel;
    wire [31:0] out;
    integer fail_count;

    mux4_1 uut (
        .in0(in0),
        .in1(in1),
        .in2(in2),
        .in3(in3),
        .sel(sel),
        .out(out)
    );

    // 在当前选择状态稳定后检查选择结果。
    task check_case;
        input integer group_number;
        input [1:0] expected_sel;
        input [31:0] expected_out;
        begin
            if ((sel !== expected_sel) || (out !== expected_out)) begin
                fail_count = fail_count + 1;
                $display("FAIL: Group %0d, sel=0x%0h, out=0x%08h, expected=0x%08h",
                         group_number, sel, out, expected_out);
            end
            else begin
                $display("PASS: Group %0d, sel=0x%0h, out=0x%08h",
                         group_number, sel, out);
            end
        end
    endtask

    initial begin
        fail_count = 0;

        // 四路固定测试数据。
        in0 = 32'h11111111;
        in1 = 32'h22222222;
        in2 = 32'h33333333;
        in3 = 32'h44444444;

        // 四组测试分别占用 0-20 ns、20-40 ns、40-60 ns 和 60-80 ns。
        sel = 2'b00;
        #20 check_case(1, 2'b00, 32'h11111111);

        sel = 2'b01;
        #20 check_case(2, 2'b01, 32'h22222222);

        sel = 2'b10;
        #20 check_case(3, 2'b10, 32'h33333333);

        sel = 2'b11;
        #20 check_case(4, 2'b11, 32'h44444444);

        if (fail_count == 0)
            $display("ALL TESTS PASSED");
        else
            $display("%0d TEST(S) FAILED", fail_count);

        $finish;
    end

endmodule
```

检查任务使用 `!==` 比较选择信号和输出信号，因此当输出包含 `X` 或 `Z` 时也会判定为失败。每组测试打印 `PASS` 或 `FAIL`，所有检查通过时打印 `ALL TESTS PASSED`，最后调用 `$finish` 结束仿真。
