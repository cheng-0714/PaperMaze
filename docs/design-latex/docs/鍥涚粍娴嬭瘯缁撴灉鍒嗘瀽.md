# 四组测试结果分析

## 1 测试数据

Testbench 将四路输入固定为：

| 信号 | 固定值 |
| --- | --- |
| `in0` | `32'h11111111` |
| `in1` | `32'h22222222` |
| `in2` | `32'h33333333` |
| `in3` | `32'h44444444` |

选择信号在 20 ns 边界改变。每组先保持 20 ns 并检查稳定值，再在同一个 `initial` 过程内切换到下一组，避免组合逻辑更新与并行检查语句发生调度竞争。

| 组别 | 有效时间区间 | `sel` | 被选择输入 | 预期 `out` |
| --- | --- | --- | --- | --- |
| 第一组 | 0-20 ns | `2'b00` | `in0` | `32'h11111111` |
| 第二组 | 20-40 ns | `2'b01` | `in1` | `32'h22222222` |
| 第三组 | 40-60 ns | `2'b10` | `in2` | `32'h33333333` |
| 第四组 | 60-80 ns | `2'b11` | `in3` | `32'h44444444` |

## 2 分组分析

第一组中，`sel=00`，应选择第 0 路输入。由于 `in0=0x11111111`，预期输出为 `0x11111111`。

第二组中，`sel=01`，应选择第 1 路输入。由于 `in1=0x22222222`，预期输出为 `0x22222222`。

第三组中，`sel=10`，应选择第 2 路输入。由于 `in2=0x33333333`，预期输出为 `0x33333333`。

第四组中，`sel=11`，应选择第 3 路输入。由于 `in3=0x44444444`，预期输出为 `0x44444444`。

## 3 检查方式

`check_case` 任务同时检查 `sel` 和 `out`，并使用 Verilog 的 `!==` 运算符。因此，选择信号错误、输出选择错误，以及输出为 `X` 或 `Z` 时，都会打印 `FAIL` 并增加失败计数。四组均通过时，Testbench 在 80 ns 打印 `ALL TESTS PASSED` 后结束。
