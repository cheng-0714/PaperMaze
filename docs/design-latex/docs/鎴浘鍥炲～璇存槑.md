# 截图保存和报告回填说明

本目录不包含伪造的 Vivado 图片。安装 Vivado 的电脑完成操作后，将真实截图复制到 `screenshots/`，再回填报告。

## 1 需要带回的文件

| 文件名 | 来源 | 用途 |
| --- | --- | --- |
| `screenshots/mux4_1_waveform.png` | Vivado Behavioral Simulation | 展示 0-80 ns 四组功能仿真波形 |
| `screenshots/mux4_1_schematic.png` | Vivado RTL Analysis Schematic | 展示 RTL 级原理图 |

`screenshots/README.md` 是目录说明，不是实验截图。不要用绘图软件或 Python 生成图片代替 Vivado 截图。

## 2 波形截图回填

1. 在 Vivado 中运行 `Run Behavioral Simulation`。
2. 确认波形窗口显示 `in0`、`in1`、`in2`、`in3`、`sel`、`out`。
3. 将数据总线设置为 **Radix -> Hexadecimal**。
4. 使用 **Zoom Fit** 或手动调整时间轴，确保 0-80 ns 完整可见。
5. 确认四组输出分别为 `11111111`、`22222222`、`33333333`、`44444444`。
6. 截图保存为 `mux4_1_waveform.png`。
7. 打开图片检查没有裁剪掉信号名、时间轴或 Vivado 标题栏。

在 `docs/实验报告新增章节.md` 中，将占位行

```text
【图 X：四路多路选择器四组功能仿真波形】
```

替换为该图片，并按原报告已有图号顺序修改 `X`。图下方保留四组数据分析，同时以真实波形为准核对输出。

## 3 原理图截图回填

1. 打开 **RTL Analysis -> Open Elaborated Design -> Schematic**。
2. 展开 `mux4_1`，确保端口和主要连接可读。
3. 截图保存为 `mux4_1_schematic.png`。
4. 在报告中将占位行

```text
【图 X：四路多路选择器 Vivado RTL 原理图】
```

替换为该图片，并按原报告已有图号顺序修改 `X`。

## 4 回填前检查

- 图片确实来自 Vivado 窗口，而不是模拟绘制图。
- 波形覆盖完整 0-80 ns。
- 波形同时包含六个指定信号。
- `sel` 和数据输出的显示格式便于阅读。
- 原理图能够看到四路输入、`sel` 和 `out`。
- 报告中的源代码与 `rtl/mux4_1.v`、`sim/mux4_1_tb.v` 完全一致。
- 报告中没有把理论预期写成尚未核对的实测结果。
