# PaperMaze 纸境寻路实验室 · 演示视频口播稿（定稿）

按痛点、产品、操作、价值展开。口播正文约 1000 字以内；时间为镜头安排参考，可留出演示操作时间。括号里是画面提示，不念出来。

## 1. 开场：痛点（0:00–0:20）
（画面：首页全屏，羊皮纸底色和三幕场景卡片）

学 BFS 和 A*，只看伪代码和结果图，很难看清算法为什么先走这一格。

## 2. 产品是什么（0:20–0:40）
（画面：鼠标划过三幕卡片，停在第一幕“雾港残卷”）

PaperMaze 用欧洲奇幻故事引导学习：雾港残卷、荆棘修道院、孤崖圣所三幕，分别对应 DFS、Prim、Kruskal 生成方式。旧纸和钴蓝蚀刻把迷宫变成旅途中的地图。故事不是替算法给答案，而是带你先自己探索，再看 BFS 和 A* 寻路，最后单步拆开看。

## 3. 自己先走一遍（0:40–1:05）
（画面：点“密匙”，选 11×11 和种子，点“绘制舆图”；切到“手持火把”，用方向键走，故意撞一次墙，走到终点）

先填尺寸和种子。生成方式、尺寸和种子相同，就能复现初始地图，也能分享挑战码。
切到「手持火把」，用方向键或 WASD 走；撞墙不移动，抵达终点后记录步数并保存。

## 4. BFS 和 A* 同图对比（1:05–1:45）
（画面：切到“算法寻路”，先跑 BFS，再跑 A*；拖倍速滑条，暂停一次；镜头移到下方“寻路手记”）

自己走完，先跑 BFS，看搜索逐层扩展；再跑 A*，看距离估计如何引导选择。在这类四方向、单位代价地图上，两者都能找到最短路径。
回放支持 0.5 到 5 倍速和暂停。「寻路手记」比较路径长度、访问节点和计算耗时，动画时间不计入耗时。

## 5. 单步讲解：把算法拆开看（1:45–2:30）
（画面：切到逐步讲解，选 A*；点“下一步”几次；鼠标指 g、h、f；点“后退一步”）

切到逐步讲解，选 A*。每点「下一步」，推进一个事件，查看候选序列、当前格子和父节点。g 是已走步数，h 是到终点的估计距离，f 是两者之和；A* 选择 f 最小的候选格。
没看懂就点「后退一步」。BFS 也能单步查看，显示的是普通队列。

## 6. 迷宫是怎么生成的（2:30–3:00）
（画面：打开生成器实验台，依次选 DFS、Prim、Kruskal，观看打通过程和指标）

生成器实验台还能拆开迷宫的构造过程。DFS 深入后回溯，Prim 扩展前沿，Kruskal 用并查集合并区域。页面展示打通的边与连通分量，也能比较结构指标。

## 7. 编辑、无解和记录恢复（3:00–3:20）
（画面：开距离热力图；用“立石”把终点封住，跑 BFS 显示无解；刷新页面，点“足迹”和“重访”）

热力图显示通路格到终点的距离。用「立石」封住终点，再跑 BFS，系统提示无解，不画假路径。
完成搜索或手动通关后，运行快照存入 SQLite。刷新后点「足迹」「重访」，恢复地图、起终点和结果。AI 解读没配密钥时使用本地规则。

（画面：回到首页全景，淡出到项目名）

从亲自探索，到同图对比，再到单步推演，故事把学习串起来，真实数据解释算法。代码、测试和文档都在仓库里。谢谢观看。
